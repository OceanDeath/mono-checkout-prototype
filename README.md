# Mono Checkout Prototype

Прототип чекаут-флоу для приложения, сверстанный по фрейму **Market-Drafts**
из Figma. iPhone 13 mini (375 × 812). Чистый HTML + CSS + ванильный JS.

## Превью

Опубликовано через GitHub Pages: https://USERNAME.github.io/REPO/
(замени `USERNAME` и `REPO` на свои после первого пуша)

## Локально

Просто открой `index.html` в браузере. Никакой сборки не нужно.

## Структура

```
index.html              — основная страница с разметкой и стилями
assets/                 — иконки, картинки, бейджи Нової Пошти
```

## Основные интеракции

- Скролл сворачивает синюю шапку до 96 px и добавляет тонкую тень
- Сегменты «Частинами / Повністю» и «Доставка / Самовивіз» переключаются по клику
- Опции доставки разворачиваются/сворачиваются: при выборе появляется адрес
  и кнопка «Змінити …»; невыбранные показывают только тайтл и подзаголовок

## Шрифт

В коде используется `SF Pro Text` через `local()` — на macOS / iOS
подхватится системный, в остальных браузерах будет fallback на
`-apple-system` / `Segoe UI` / `sans-serif`. В Chromium-Linux fallback
шире, поэтому длинный адрес может занимать на 1 строку больше — это
не баг вёрстки, а особенность шрифта в превью-окружении.
